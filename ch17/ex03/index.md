## npm に同梱されている npx を利用することにはどのような利点があるか

### npx (node package executer) はパッケージの実行ツール

### 一時的な実行が可能
- インストールされていないパッケージでも自動的に探してインストールし、実行完了後にインストールしたパッケージを削除する
- これによってパッケージをローカルにインストールする必要がなくなるため、開発環境を汚さずにパッケージを試したり、複数バージョンのパッケージを管理できる

### パッケージの指定
- 特定のバージョンのパッケージを実行することが可能で、別のバージョンのパッケージを切り替えて実行することができる
